# 💫 About Me
Hi, I'm **Mehdi**, a Software & AI Engineer based in Munich, Germany. I specialize in building autonomous AI agents, LLM integrations, and scalable full-stack web platforms.

### 🤖 AI Agents, LLMs & Machine Learning
I build production AI systems focused on automated troubleshooting, intelligent data collection, and multi-step agentic workflows. My work spans orchestrating LLM agents, integrating RAG pipelines across vector databases, and building custom tool-calling architectures. Alongside modern generative AI, I have a strong foundation in deep learning and data science, having built and deployed models using Convolutional Neural Networks (CNNs) for computer vision and RNNs/GRUs for sequential time-series forecasting.

### ⚡ Full-Stack & Platform Engineering
On the software engineering side, I architect developer SDKs, high-performance APIs, and responsive web applications. I work primarily across the TypeScript and Python ecosystems—leveraging **NestJS**, **Django**, and **.NET** on the backend, paired with **React** on the frontend and diverse data layers ranging from relational and document stores to high-dimensional vector databases.
